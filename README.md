# Project 1 Banking App
Authors: Xing-Wei and Ronny

#### The application purpose
The purpose of this application is to allow customers to register and manage bank accounts, deposit and withdraw money, transfer money between accounts, and review transaction history. Bank employees can log in, assist customers with account operations, and record notes and activity logs on customer accounts.
